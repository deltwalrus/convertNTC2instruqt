# convertNTC2instruqt
This Python script converts (a very specific format and arrangement of) files from the Network to Code lab format to a format the can be imported into Instruqt.

## Note
Some issues still remain, the process is *not* yet fully automated (see issues tab). But this is A Good Start™️

## Usage
`convert2instruqt.py [-h] [--template_slug TEMPLATE_SLUG] [--team_slug TEAM_SLUG] old_lab_path new_track_title`
